# Развивать Task Manager как локальную траекторию SCB

Бенчмарк измеряет, насколько далеко Codex продвигается с дополнительными инструкциями и без них, поэтому оба варианта должны получать одинаковую накопительную задачу для бэкенда и начинать с пустого каталога решения. Обязательный стек — Python 3.12, FastAPI, SQLAlchemy 2 и SQLite; REST-контракт доступен через `task_manager.main:app`, проверяется ASGI TestClient и одной проверкой запуска Uvicorn. Единственный источник истины — один бэкенд и одна база данных: офлайн-клиенты, протоколы синхронизации, внешние очереди и поведение распределенных систем не входят в задачу.

Траектория состоит из 15 чекпоинтов в одном сохраняемом рабочем каталоге. Core охватывает только функцию текущего чекпоинта; SCB повторно запускает файлы всех прошлых чекпоинтов как Regression, а `all-core-cases` останавливает траекторию только при ошибке текущего Core. Результаты Functionality, Error и Regression остаются отдельными показателями; раннер SCB ради изменения этой классификации не модифицируется.
