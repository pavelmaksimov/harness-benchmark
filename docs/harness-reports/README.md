# Отчёты по влиянию harness — индекс

> Три инсайта, которые делают эти отчёты другими, чем leaderboard.

## Рамка (твои три правила)

1. **Не все харнесы — марафонцы.** Одним нужен один чекпоинт-витрина, другим — 14-ступенчатая RealWorld-лестница. Тестировать всех на одном марафоне — как мерить скорость лодки по пустыне.

2. **Разнородное не сравнивают.** Требования (doorstop/strictdoc) соревнуются с требованиями, тесты (tdd) — с тестами, память (supermemory) — с памятью, экономия (benjamin-plus) — с экономией. Все — с baseline как контрольной группой.

3. **У каждого свой вектор влияния.** Токены и LOC — не универсальная валюта. У одного это налог, у другого — продукт, у третьего — шум. Измерять надо след в коде + след в диалоге агента.

## Карта харнесов по классам

| Класс | Харнесы | Идеальная задача | Главный вектор |
|-------|---------|------------------|----------------|
| **Traceability** (требования как дисциплина) | doorstop, strictdoc | 1–2 CP (file_backup CP1-2 или RealWorld CP1) | Валидность спеки, стабильность UID, налог времени/токенов |
| **Verification** (тесты как спека) | tdd | 1 задача, 2–3 seams | Качество тестов, вертикальные срезы, survival при рефакторе |
| **Memory** (межсессионная память) | supermemory | 14 CP RealWorld (длинный горизонт) | Hit-rate памяти, реюз фиксов, снижение повторных ошибок |
| **Efficiency** (экономия шагов) | benjamin-plus-skill | Любая, достаточно 1 CP | Токены, время, шаги, степень keyhole-чтения |

## Метод: как оценивали

- **Кодовый след**: снапшоты `results/.../snapshot/` — что осталось после агента (doorstop-docs/, strictdoc-docs/, tests/).
- **Диалоговый след**: `checkpoint_N/agent/messages.jsonl` — как агент реально использовал скилл (вызовы `doorstop -j .`, `strictdoc export`, `search-memory.js`, батчи benjamin).
- **Метрики из `metrics/`**: только релевантные нарезаем; LOC/tokens для требований — шум, для tdd — продукт.

Все цифры — из `realworld-opencode-x-preview-f-free-high-all-20260822-1838` (N=1 на arm, gpt-модель x-preview-f-free, thinking high) + smoke-прогоны. N=1 ≠ наука, но для вектора влияния достаточно — след в коде однозначен.
