# 04 — CP2: проекты и Входящие

**What to build:** Позволить пользователю необязательно объединять задачи в проекты, оставлять их во Входящих и замораживать проект архивированием без потери доступа к данным.

**Blocked by:** 03 — Подтвердить пригодность CP1 для эксперимента.

**Status:** done

- [x] Проекты можно создать, получить, вывести, переименовать, архивировать и восстановить.
- [x] Задача перемещается между проектом и Входящими.
- [x] Архивированный проект и его задачи доступны для чтения, но любые изменения запрещены до восстановления.
- [x] Core CP2 и вся Regression CP1 проходят на эталонной реализации.
