# 01 — Создать запускаемую основу задачи Task Manager

**What to build:** Подготовить новую накопительную задачу SlopCodeBench, которую раннер распознаёт как траекторию из 15 чекпоинтов. Зафиксировать общий внешний HTTP-контракт и переиспользуемые средства проверки через ASGI, управляемые часы, изолированную SQLite и отдельный запуск Uvicorn.

**Blocked by:** None — can start immediately.

**Status:** done

- [x] Раннер обнаруживает задачу и все 15 чекпоинтов в правильном порядке с повторным запуском прошлых проверок.
- [x] Проверочная основа поддерживает изолированную базу, двух владельцев данных, подстановку значений между HTTP-шагами и управляемое время без ожидания.
- [x] Ошибки, идентификаторы, даты, моменты времени, `PATCH`, авторизация и постраничная выдача имеют единый внешний договор.
- [x] То же ASGI-приложение можно проверить через TestClient и запустить отдельным процессом Uvicorn.
