**Blocked by:** 12 — CP10: неизменяемая история задач.

**Status:** done

- [x] Для сочетания задачи и конкретного точного срока создаётся не более одного уведомления.
- [x] Изменение будущего срока заменяет ожидающее напоминание; дата срока уведомление не создаёт.
