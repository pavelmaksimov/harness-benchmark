# Combined harness

This pin combines:

- `supermemory`
- `graphify`
- `ponytail`
- `thermo-nuclear-code-quality-review`
- `doorstop`
- `tdd`

The payload is copied from the individual pinned harnesses into `skills/` and
`home/`. Rebuild this directory and rerun `scripts/pin_harness.py` when one of
the component harnesses is intentionally updated.
