# Task Manager

Личный менеджер задач для нескольких изолированных учетных записей. Каждая учетная запись управляет только собственными проектами, задачами, состояниями и отчетами.

## Владение и организация

**Учетная запись**:
Личное пространство пользователя и единственная граница владения данными.
_Избегать_: Команда, рабочее пространство

**Входящие**:
Системное место для задач, не относящихся ни к одному проекту.
_Избегать_: Проект по умолчанию

**Проект**:
Необязательный пользовательский контейнер для задач. Архивированный проект и его задачи доступны только для чтения до восстановления.
_Избегать_: Список, папка

## Задачи и состояния

**Задача**:
Личная единица работы с заголовком, описанием, состоянием и необязательным сроком. Задача находится во Входящих либо в одном проекте.
_Избегать_: Карточка, дело

**Пользовательское состояние**:
Именованная колонка процесса, общая для всех проектов учетной записи. Пользовательские состояния можно добавлять и упорядочивать; каждое относится к одной системной категории.
_Избегать_: Этап, статус

**Системная категория**:
Устойчивый смысл пользовательского состояния: `todo`, `in_progress`, `done` или `canceled`. В учетной записи всегда есть хотя бы одно состояние каждой категории.
_Избегать_: Пользовательское состояние

**Начальное состояние**:
Единственное состояние категории `todo`, автоматически назначаемое новой задаче, если состояние не указано.
_Избегать_: Состояние по умолчанию

**Канбан-доска**:
Представление задач по колонкам пользовательских состояний с ручным порядком внутри каждой колонки.
_Избегать_: Системные категории

**Ветвь задач**:
Задача и все ее потомки в дереве подзадач. Вся ветвь принадлежит одному проекту либо Входящим и переносится целиком.
_Избегать_: Зависимости задач

**Удаленная задача**:
Логически скрытая задача, которую можно восстановить. Удаление и восстановление родителя применяется ко всей ветви.
_Избегать_: Архивированная задача

## Время и автоматизация

**Дата срока**:
Календарный день без времени; для него уведомление не создается.
_Избегать_: Полночь срока

**Точный срок**:
Момент времени с часовым поясом, от которого определяется просрочка и создается уведомление.
_Избегать_: Дата срока

**Повторяющаяся задача**:
Отдельная корневая задача без подзадач с правилом ежедневного, еженедельного или ежемесячного повторения.
_Избегать_: Шаблон дерева задач

**Экземпляр повторения**:
Задача, заранее созданная из повторяющейся задачи в пределах горизонта планирования.
_Избегать_: Копия задачи

**Уведомление**:
Личная запись о наступившем точном сроке, которую пользователь может прочитать и отметить прочитанной.
_Избегать_: Email, push-сообщение

## История и аналитика

**История изменений**:
Неизменяемая последовательность значимых изменений задачи, включая переходы между состояниями и завершение.
_Избегать_: Текущее состояние задачи

**Отчет**:
Аналитический результат, рассчитанный по разрешенным измерениям, показателям и фильтрам учетной записи.
_Избегать_: Произвольный SQL-запрос

**Сохраненный отчет**:
Именованное определение отчета, которое при каждом выполнении рассчитывается по актуальным данным.
_Избегать_: Снимок результатов
